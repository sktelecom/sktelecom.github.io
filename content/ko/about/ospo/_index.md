## OSPO란?

OSPO(Open Source Program Office, 오픈소스 프로그램 사무소)는 기업의 오픈소스 관리를 전담하는 조직입니다. 기술, 법무, 인프라 등 여러 부서가 협력해 오픈소스 정책을 수립·실행하고, 커뮤니티와의 관계를 관리합니다.

SK텔레콤의 OSPO는 개발자와 법무팀을 잇는 가교로서, 개발자가 오픈소스의 이점을 최대한 활용하도록 지원하는 동시에 라이선스·보안 관련 법적 리스크를 관리합니다. 오픈소스 도입이 단순한 기술 선택이 아니라 전략적이고 책임감 있는 결정이 되도록 하는 것이 목표입니다.

## SK텔레콤 OSPO의 주요 역할

{{% alert title="한눈에 보기" %}}
- **전략 수립**: 오픈소스 정책 수립·개선, 활용 현황 분석, 중장기 로드맵 제시
- **교육 및 가이드**: 정기 교육, 사용/기여/공개 가이드, 컴플라이언스 체크리스트 제공
- **커뮤니티 관리**: 외부 프로젝트 기여 지원, 자체 기술 오픈소스 공개·관리
- **정책 실행**: 라이선스·보안·지식재산권 점검, ONOT 등 자동화 도구 운영
{{% /alert %}}

### 1. 전략 수립

OSPO는 회사의 오픈소스 정책을 수립하고 정기적으로 개선합니다. 개발팀의 오픈소스 활용 현황을 분석하고, 중장기 로드맵을 제시해 조직이 체계적으로 오픈소스를 활용하도록 방향을 정합니다.

### 2. 교육 및 가이드

개발자를 위한 정기 오픈소스 교육을 제공하고, 사용/기여/공개에 대한 명확한 정책과 가이드를 수립합니다. 컴플라이언스 체크리스트와 템플릿을 함께 제공해 검토 과정을 단순화합니다.

### 3. 커뮤니티 관리

개발자의 외부 오픈소스 프로젝트 기여를 장려·지원하는 한편, 회사가 개발한 기술을 오픈소스로 공개해 커뮤니티에 환원합니다. 공개된 프로젝트를 관리하고 외부 기여자와의 협업을 활성화합니다.

### 4. 정책 실행

개발팀이 오픈소스를 사용할 때 라이선스 컴플라이언스를 점검하고, 보안 취약점과 지식재산권 이슈를 검토합니다. ONOT 등 자동화 도구를 운영해 반복적인 컴플라이언스 작업의 효율을 높입니다.

## SK텔레콤 오픈소스 의사결정 구조

SK텔레콤의 오픈소스 거버넌스는 OSPO(운영)와 OSRB(의사결정)의 2단계 협력 구조입니다. OSPO는 개발팀으로부터 오픈소스 도입·기여·공개 요청을 받아 초기 검토를 수행하고, 이를 OSRB(Open Source Review Board)에 상정합니다. OSRB는 기술, 법무, 인프라, 보안 부서의 책임자로 구성되어 OSPO의 검토 결과를 바탕으로 라이선스·보안·지식재산권 측면의 최종 심의와 승인 여부를 결정합니다.

![OSPO와 OSRB의 2단계 검토 구조](ospo-osrb-flow.svg "개발팀 요청이 OSPO 초기 검토를 거쳐 OSRB 최종 심의로 이어지는 흐름")

[OSRB에 대해 자세히 알아보기](/about/osrb/)

## OSPO가 제공하는 가이드 및 지원

### 오픈소스 사용하기

외부 오픈소스를 도입할 때는 다음 절차를 거칩니다.

1. 라이선스 확인 및 정책 부합 검토
2. 기존 라이선스와의 호환성 검증
3. 보안 취약점 점검
4. 사용 승인 및 기록 (추후 감사·법적 분쟁 대비)

[오픈소스 사용 가이드 보기](/guide/use/)

### 오픈소스 기여하기

외부 프로젝트에 기여할 때는 다음 절차를 지원합니다.

1. 대상 프로젝트의 라이선스, 활동 상태, 법적 리스크 검토
2. CLA/DCO 검토 및 서명
3. 프로젝트 라이선스·정책에 맞는 코드 기여
4. 기여 코드의 라이선스 명시 및 지식재산권 보호 확인

[오픈소스 기여 가이드 보기](/guide/contribute/)

### 오픈소스 공개하기

기술을 오픈소스로 공개할 때는 다음 절차로 진행합니다.

1. 핵심 지식재산권·보안 문제 여부의 사전승인 검토
2. 라이선스 선정 (SK텔레콤은 통상 Apache 2.0 사용)
3. 내부 정보 제거 및 문서화
4. GitHub 공개와 커뮤니티 관리

[오픈소스 공개 가이드 보기](/guide/release/)


## 문의 및 연락처

### 이메일 연락

SK텔레콤 OSPO와 오픈소스 관리에 관한 모든 문의는 opensource@sktelecom.com으로 보내실 수 있습니다. 오픈소스 사용, 기여, 공개 관련 상담부터 정책 문의, 기술 지원까지 다양한 주제에 대해 지원을 받을 수 있습니다.

### 온라인 채널

SK텔레콤의 오픈소스 프로젝트는 GitHub (https://github.com/sktelecom)에서 확인할 수 있습니다. 각 프로젝트의 Issues 섹션을 통해 버그 리포트, 기능 요청, 일반적인 질문 등 피드백을 제공할 수 있으며, SK텔레콤 개발팀이 이를 모니터링하고 응답합니다.
